# 박스 치수 계산기

액자 박스의 두께(T)·가로(W)·세로(H)를 입력하면 보정 치수와 전개도를 실시간으로 그려 주는 웹 앱입니다.
외부 API 없이 브라우저에서만 동작합니다.

## 계산식

- T' = T + 5, W' = W + 10, H' = H + 10
- 전체 가로 = T' + W' + T'
- 전체 세로 = 40(날개) + T' + H' + T' + H'

## 로컬 실행

**필요:** Node.js

1. 의존성 설치: `npm install`
2. 개발 서버 실행: `npm run dev` (http://localhost:3000)
3. 배포용 빌드: `npm run build`
